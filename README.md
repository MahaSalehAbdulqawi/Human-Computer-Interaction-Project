# BAKECRAFT APP

Human-Computer Interaction (HCI) group project that introduces "BAKECRAFT" APP which is a bakery marketplace connecting customers with bakeries that offer personalized baking services. The app enables users to order customized baked goods tailored to their preferences through flexible personalization features and an intuitive mobile experience.

## Project Overview

The project explores how user-centered design principles can create a seamless and enjoyable experience for browsing and ordering freshly baked goods.

Key features include:
- Browsing bakery products by category.
- Exploring special offers and seasonal items.
- Viewing product details, ingredients, and prices.
- Customizing orders based on user preferences.
- Choosing delivery or pickup options.
- Navigating a simple and intuitive ordering flow.

## Design Focus

The project applies core HCI principles, including:
- Usability and intuitive navigation.
- Information architecture and visual hierarchy.
- Consistent interface design.
- User-centered interaction design.
- Accessibility and ease of use.
