# BAKECRAFT

BAKECRAFT is a Human-Computer Interaction (HCI) project focused on designing a distinctive bakery mobile application that offers a modern and convenient way to buy baked goods online. The concept goes beyond a simple food-ordering app by emphasizing personalization, product discovery, and a smooth user experience for customers who want freshly made bakery items in a more engaging and memorable way.

## Project Overview

This repository presents the design and prototype for a new bakery-focused app concept. It includes:
- an interactive Figma prototype
- supporting project materials and design documentation

The goal of BAKECRAFT is to explore how creative interface design can improve the experience of browsing, selecting, and ordering bakery products in a way that feels modern, user-friendly, and visually appealing.

## Project Idea

The new project idea is a bakery app that sells freshly baked goods in a distinctive and customized way. The application is designed to help users:
- explore bakery products and special offers
- browse categories such as breads, pastries, cakes, and desserts
- customize or personalize orders based on preferences
- view product details, ingredients, and prices
- place an order easily through a simple and intuitive flow
- choose delivery or pickup options based on convenience

This concept highlights a unique bakery experience that combines food ordering with attractive presentation, branding, and user-centered interaction design.

## Objective

The main objective of this project is to design a clean, engaging, and user-friendly interface for a bakery application where users can:
- browse a wide range of bakery products
- discover specialty and seasonal items
- view product details and customization options
- simulate ordering and checkout steps
- enjoy a smooth and accessible mobile experience

## Design Focus

BAKECRAFT highlights key HCI principles, including:
- usability
- clear information hierarchy
- intuitive navigation
- visual consistency
- user-friendly interactions
- accessibility-conscious design
- engaging product presentation
