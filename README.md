# BAKECRAFT

A Human-Computer Interaction (HCI) project focused on designing and evaluating a bakery-themed mobile application prototype. The goal of this project is to explore user-centered design, usability, and interaction flow in a realistic digital product experience.

## Project Overview

This repository contains the design materials for the BAKECRAFT app prototype, including:
- an interactive Figma-based prototype
- a project PDF showing the application concept and design details
The project is intended to demonstrate how thoughtful interface design can improve usability, accessibility, and user satisfaction in a food-ordering and browsing experience.

## Objective

The main objective of this project is to design a clean and user-friendly interface for a bakery application where users can:

- browse bakery products
- view categories and specialties
- explore product details
- place or simulate an order
- navigate through a simple, intuitive experience

## Design Focus

This project highlights key HCI principles such as:

- usability
- clear information hierarchy
- intuitive navigation
- visual consistency
- user-friendly interactions
- accessibility-friendly interface design
